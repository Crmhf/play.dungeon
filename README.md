# 地牢双雄 · DUNGEON DUO

> 两个老友在暗黑地牢里一直砍怪，每波结束变强一点，扛到最后就是胜利。
> 俯视同屏双人合作生存 Roguelike · 万圣节像素风 · H5 Canvas 单页游戏

## 快速开始
无需构建，静态服务即可运行：
```bash
python3 -m http.server 8931
# 打开 http://localhost:8931
```

## 核心循环
开局选角色 → 怪潮(每波递增强度) → 清场 → **3选1升级** → 更强怪潮 → 每6波一关 Boss → 5关30波通关
失败(双人都死) → 升级清零 → 再来一局(肉鸽核心)

## 操作(同屏双人)
| 角色 | 移动 | 攻击 | 闪避 | 技能 |
|---|---|---|---|---|
| P1 | WASD | C | F | B |
| P2 | 方向键 | L | I | J |

Esc 暂停 · M 静音

## 角色(4选2)
| 角色 | 定位 | 血 | 特色 |
|---|---|---|---|
| ⚔️ 骑士 | 近战肉盾 | ★★★★★ | 旋风斩 |
| 🏹 弓手 | 远程 | ★★★ | 穿透箭 · 箭雨 |
| 🔮 法师 | 中距AOE | ★★ | 弹射魔法 · 奥术爆发 |
| 🗡️ 盗贼 | 极快高闪 | ★ | 双刀 · 暗影突袭 |

## 关卡(5主题×6波)
1. 暗黑地牢(暗紫) 2. 阴森墓地(墨绿) 3. 沙石古堡(暖红) 4. 火焰深渊(橙黑) 5. 万圣夜宴(橙紫)
每关末波为 Boss(巨型怪 / 南瓜王多阶段)，过关走传送门切主题。

## 升级(14种,每波3选1)
进攻: 伤害/攻速/弹道数/弹道速/范围 · 防御: 血量/无敌帧/闪避/回血 · 特效: 吸血/击杀爆炸/雷霆/召唤随从/反伤

## 技术
- 纯 HTML+Canvas+JS,无依赖,60fps 同屏百怪
- 敌人: 横向精灵表逐帧动画 · AI分级(冲撞/围猎/远程/投弹/冲刺/隐匿/召唤)
- 打击感: 命中停顿 + 屏幕震动 + 粒子 + 飘字 + 受伤闪白
- 音频: Web Audio 池化音效(刀/弓/法/爆炸) + minimax AI 生成 BGM
- 美术: 2000套像素素材(Enemies/2D Pixel Dungeon) + minimax gpt-image 生成关卡背景
